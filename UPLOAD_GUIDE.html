🐾 Baby Princess Episode Upload Guide

Quick Start: Adding New Episodes

Follow these steps to upload new episodes from your live site:

Step 1: Export Your Episode HTML

From your live site, save the complete HTML5 episode file locally. Make sure it includes:

  • ✅ All inline CSS (no external stylesheets)
  • ✅ All SVG graphics (embedded, not external)
  • ✅ All JavaScript (inline, not external)
  • ✅ Complete HTML structure
Step 2: Name the File Correctly

Save your episode with the naming pattern:

episodes/ep7.html episodes/ep8.html episodes/ep9.html etc.
Step 3: Update Episode Links

Edit the navigation in your new episode's footer to link to adjacent episodes:

<!-- In the footer section --> <a href="ep6.html" ...>◀ EP.6</a> <a href="ep8.html" ...>EP.8 ▶</a>

And update the previous episode's footer to link to your new one.

Step 4: Update index.html

Add your new episode to the home page navigation. Find the episodes list and add:

<a href="episodes/ep7.html"> <div class="ep-card"> <div class="ep-number">EP.7</div> <div class="ep-title">EPISODE TITLE HERE</div> </div> </a>
Step 5: Push to GitHub

Use Git to upload your new files:

git add episodes/ep7.html git add index.html git commit -m "Add EP.7 - YOUR EPISODE TITLE" git push origin main

Folder Structure

Your repository should look like this:

Princessbaby/ ├── index.html (Home page) ├── README.md (Documentation) ├── UPLOAD_GUIDE.html (This file) └── episodes/ ├── ep1.html (ICE ICE SHADY) ├── ep2.html (LIKE, SHARE & LIE) ├── ep3.html (PILL PUSHERS & PROFIT) ├── ep4.html (BREAKING BAD NEWS) ├── ep5.html (HOLY HUSTLE) ├── ep6.html (WORLD GONE WILD) ├── ep7.html (YOUR NEW EPISODE) └── ep8.html (FUTURE EPISODE)

Episode Template Checklist

Before uploading, make sure your episode has:

Component Required Example
Episode Title ✅ <title>Baby Princess Ep.7 – TITLE</title>
5 Scenes ✅ <div class="scene" id="scene1">...</div>
Scene Durations ✅ sceneDurations = [10000, 14000, 12000, 14000, 10000]
SVG Graphics ✅ Baby Princess character, props, backgrounds
Dialogue Bubbles ✅ <div class="bubble">...</div>
Control Buttons ✅ PREV, PAUSE/PLAY, NEXT
Navigation Links ✅ Home, Previous Ep, Next Ep
Progress Bar ✅ <div class="progress-bar">

Quick Reference: Important File Paths

<a href="../index.html">🏠 HOME</a> <a href="ep7.html">EP.7 ▶</a> <a href="ep6.html">◀ EP.6</a> episodes/ep1.html episodes/ep2.html etc.
⚠️ Important: Make sure all graphics, styles, and scripts are self-contained in the HTML file. Do NOT use external stylesheets or image files — everything must be inline (CSS in <style> tags, graphics as SVG, scripts in <script> tags).
✅ Pro Tips:
  • Use consistent color schemes and styling with other episodes
  • Each episode should be about 60 seconds (adjust sceneDurations accordingly)
  • Test all links and animations before pushing to GitHub
  • Keep character SVGs consistent in size and style
  • Update README.md with new episode details
